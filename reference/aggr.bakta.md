# Callback function for aggregating Bakta annotations for each cell

To be called from BascetAggregateMap

## Usage

``` r
aggr.bakta(bascetFile, cellID, bascetInstance)
```

## Arguments

- bascetFile:

  An opened Bascet file

- cellID:

  Cell ID

- bascetInstance:

  A Bascet instance

## Value

Bakta annotations for one cell
